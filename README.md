Superstore Sales & Profit Analysis Dashboard

📊 Project Overview

This project focuses on analyzing Superstore sales and profitability using Power BI. The interactive dashboard provides insights into sales performance, profit trends, customer segments, regional distribution, and product performance to support data-driven business decisions.

🎯 Project Objectives

- Analyze overall sales, profit, and quantity sold.
- Compare sales and profitability across different regions.
- Understand customer segment contributions.
- Identify monthly sales trends and top-performing months.
- Analyze top-selling and loss-making products.
- Explore geographic sales performance.

🛠️ Tools & Technologies

- Power BI – Dashboard development and data visualization
- Microsoft Excel – Dataset storage and data source

📈 Dashboard Features

- KPI cards for key business metrics.
- Regional sales and profit analysis.
- Customer segment sales distribution.
- Monthly sales trend analysis.
- Top products by sales.
- Loss-making product analysis.
- Geographic sales visualization.
